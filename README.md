# RISC-V CPU Architectures

This repository contains two Verilog HDL processor implementations:

- **Single-Cycle CPU** — a single-cycle RISC-V processor.
- **Five-Stage Pipelined CPU** — a RISC-V processor organized into IF, ID, EX, MEM, and WB stages.

Each project folder contains RTL source, the supplied testbench, and program/initialization files. FPGA tool-generated output, temporary files, and editor backups have been excluded.
